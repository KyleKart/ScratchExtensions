ElmoBear's Extensions

My Scratch Extensions which I like the most or think are the most complete!

Save the file or copy its text as most of these need to be unsandboxed to work.

Pitchano

Converts piano note numbers to pitch numbers. May be off by a minor amount.

Legacy Blocks

Recreations of old blocks from early and beta versions of Scratch.

Extra Blocks

Vanilla-compatible modded custom blocks with fancy menus and inputs.

Theme Color

Dynamically change your browser theme! Exclusive to PWAs and supported browsers like Vivaldi.

Menu-bar Changer

An extension that rearranges the TW menu-bar options to how I think they should be.

Key Remote

A key detection extension designed specifically for remotes including Bluetooth ones.

Clipboard

A ScratchX compatible extension for interacting with the clipboard.
Has known issues in browsers like Pale Moon.

JSON

A X3non extension with tools for parsing, reading, and handling JSON data.
Uses X3non-only block types.

Comment Blocks

A X3non extension for adding comments nested inside of your code.
Uses X3non-only block types.

Advanced Costumes

An extension for appending text, shapes, and images to an SVG costume.
